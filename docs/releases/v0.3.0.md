Prima release con installer di **PERSONA**, il laboratorio local-first per creare, mantenere e simulare identità artificiali persistenti. L'app desktop avvia il proprio server locale (`127.0.0.1`), conserva tutti i dati sul computer e non richiede account né servizi cloud.

## Download

| Sistema | File |
|---|---|
| Windows 10/11 (x64) | `PERSONA-Setup-0.3.0-x64.exe` |
| macOS Apple Silicon | `PERSONA-0.3.0-mac-arm64.dmg` |
| macOS Intel | `PERSONA-0.3.0-mac-x64.dmg` |
| Linux (x64) | `PERSONA-0.3.0-linux-x86_64.AppImage` oppure `PERSONA-0.3.0-linux-amd64.deb` |

`SHA256SUMS.txt` contiene le impronte SHA-256 dei file.

## Installazione

Gli installer **non sono firmati** con certificati di sviluppatore, quindi il sistema mostra un avviso al primo avvio.

- **Windows** — se compare «Windows ha protetto il PC», scegli *Ulteriori informazioni → Esegui comunque*. L'installazione è per l'utente corrente e permette di scegliere la cartella.
- **macOS** — apri il `.dmg` e trascina PERSONA in Applicazioni. Al primo avvio macOS lo blocca: apri *Impostazioni di Sistema → Privacy e sicurezza* e scegli *Apri comunque* (in alternativa, nel Terminale: `xattr -dr com.apple.quarantine /Applications/PERSONA.app`).
- **Linux** — `.deb`: `sudo apt install ./PERSONA-0.3.0-linux-amd64.deb`. AppImage: `chmod +x PERSONA-0.3.0-linux-x86_64.AppImage` e avvio diretto (serve FUSE; su Ubuntu 24.04 e successive, se l'AppImage non si apre per le restrizioni di AppArmor, usa il `.deb` oppure avvia con `--no-sandbox`).

I dati si trovano nella cartella dell'applicazione dell'utente (`…/PERSONA/data`); usa *Impostazioni → Backup* per salvarli.

## Per conversare serve un modello

PERSONA usa un LLM locale tramite **LM Studio** (o un provider compatibile OpenAI): avvia il server di LM Studio (scheda *Developer*), carica un modello e premi *Prova connessione* in *Impostazioni → Motori LLM*. Senza modello puoi esplorare l'app con il motore *Mock* (risposte segnaposto).

## Cosa contiene

- Editor completo dell'identità: biografia, psicologia (Big Five facoltativi), comunicazione, competenze, profilo linguistico, base di conoscenza (testo, Markdown, PDF).
- Dialogo in streaming con modalità dialogo, intervista e analisi esterna; memoria persistente (core, episodica, semantica, contestuale) con provenienza, riassunti incrementali e ispezione del contesto.
- Scenari narrativi isolati e simulazioni multi-personaggio (turni scelti dall'autore, rotazione o regia automatica).
- Recupero semantico multilingue facoltativo con embedding locali.
- Esportazione/importazione di personaggi e scenari, backup e ripristino del database.
- Interfaccia in italiano, inglese, francese, spagnolo, tedesco e portoghese.

## Limiti noti

- L'integrazione con LM Studio è verificata con server compatibili simulati, non ancora con un'istanza reale.
- Installer non firmati e senza aggiornamento automatico.
- Le traduzioni diverse da italiano e inglese non sono state riviste da madrelingua.
