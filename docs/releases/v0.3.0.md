Prima release con installer di **PERSONA** per **Windows**: il laboratorio local-first per creare, mantenere e simulare identità artificiali persistenti. L'app desktop avvia il proprio server locale (`127.0.0.1`), conserva tutti i dati sul computer e non richiede account né servizi cloud.

## Download

| Sistema | File |
|---|---|
| Windows 10/11 (x64) | `PERSONA-Setup-0.3.0-x64.exe` |

`SHA256SUMS.txt` contiene l'impronta SHA-256 dell'installer. Questa release non include installer per Linux e macOS: su questi sistemi PERSONA si può avviare dai sorgenti (vedi README).

## Installazione

1. Scarica ed esegui `PERSONA-Setup-0.3.0-x64.exe`.
2. L'installer **non è firmato** con un certificato di sviluppatore: se compare «Windows ha protetto il PC», scegli *Ulteriori informazioni → Esegui comunque*.
3. L'installazione è per l'utente corrente (senza privilegi di amministratore) e permette di scegliere la cartella; crea un collegamento sul desktop e nel menu Start.

I dati si trovano in `%APPDATA%\PERSONA\data`; usa *Impostazioni → Backup* per salvarli. La disinstallazione si fa da *Impostazioni di Windows → App*.

## Per conversare serve un modello

PERSONA usa un LLM locale tramite **LM Studio** (o un provider compatibile OpenAI): avvia il server di LM Studio (scheda *Developer*), carica un modello e premi *Prova connessione* in *Impostazioni → Motori LLM*. Senza modello puoi esplorare l'app con il motore *Mock* (risposte segnaposto).

## Cosa contiene

- Editor completo dell'identità: biografia, psicologia (Big Five facoltativi), comunicazione, competenze, profilo linguistico, base di conoscenza (testo, Markdown, PDF).
- Dialogo in streaming con modalità dialogo, intervista e analisi esterna; memoria persistente (core, episodica, semantica, contestuale) con provenienza, riassunti incrementali e ispezione del contesto.
- Scenari narrativi isolati e simulazioni multi-personaggio (turni scelti dall'autore, rotazione o regia automatica).
- Recupero semantico multilingue facoltativo con embedding locali.
- Esportazione/importazione di personaggi e scenari, backup e ripristino del database.
- Interfaccia in italiano, inglese, francese, spagnolo, tedesco e portoghese.

## Limiti noti

- L'integrazione con LM Studio è verificata con server compatibili simulati, non ancora con un'istanza reale.
- Installer non firmato e senza aggiornamento automatico.
- Le traduzioni diverse da italiano e inglese non sono state riviste da madrelingua.
